# Les films de plein air

Un site vitrine statique présentant un festival de cinéma en plein air.

Ce dépôt contient une page web unique avec une navigation, des sections (affiches, actualités, galerie, pré‑inscription, carte, à propos, partenaires) et des ressources associées (CSS, JS et images). Le site utilise Bootstrap 5 pour la mise en forme responsive.

## Aperçu rapide
- HTML statique (index.html)
- CSS personnalisé (css/style.css)
- JavaScript basique (js/script.js)
- Framework CSS: Bootstrap 5 via CDN
- Images incluses dans le dossier `images/`

## Démarrage rapide
Aucune installation n’est nécessaire pour consulter le site localement.

1. Téléchargez/cloner le dépôt.
2. Ouvrez le fichier `index.html` dans votre navigateur (double‑clic ou clic droit > Ouvrir avec…).

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)
- Bootstrap 5.3 (CDN)

## Personnalisation
- Styles: modifiez `css/style.css`.
- Comportements: adaptez `js/script.js`.
- Contenus (textes, images): éditez `index.html` et remplacez/ajoutez des fichiers dans `images/`.

## Accessibilité et bonnes pratiques
- Balises sémantiques HTML utilisées (header, main, section, nav, etc.).
